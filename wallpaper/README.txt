Water (Autumn Leaves) — Classic desktop recreation

Open index.html in a WebGL-capable browser. Click for ripples; Space pauses.
No dependencies, server, or network connection are required.

Sucrose: import the Sucrose ZIP into the library, then choose Use.
Lively: import the Lively ZIP into the library.
Wallpaper Engine: create a web wallpaper from index.html in its editor.
Desktop input forwarding depends on the engine's settings and focus.

Original AOSP images, 14 leaves, 8 atlas cells, and 10 analytic ripple sources.
The image is cropped without stretching for desktop screens. No fluid solver.
Browser interactions and simulation checks passed. Cross-engine desktop testing
and comparison with specific Samsung firmware are still pending.

Source, installation notes, and test instructions:
