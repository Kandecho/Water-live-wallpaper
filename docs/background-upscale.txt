Study 04 background provenance

Original: reference/original-assets/pond.jpg (unchanged AOSP texture).
Approved result: reference/derived/hd-pond-4k.png.
It retains the original 1024x1024 atlas layout at 4x resolution; effective
crop (0,224,958,1024) becomes (0,896,3832,4096). Padding repeats edge pixels.

Compared: Lanczos, realesr-animevideov3 native 2x, realesrgan-x4plus,
realesrnet-x4plus, realesrgan-x4plus-anime.
Selected: RealESRNet for restrained edges and smooth blue/purple gradients.
The user approved this 4K result before its integration into Study 04.

Pipeline: original crop -> RealESRNet 4x -> Lanczos /2 (2K candidate)
         -> RealESRNet 4x -> Lanczos /2 (4K result).
This is a reconstruction, not recovered true high-resolution detail. Tiny
silhouette features are simplified. No image-gen/diffusion repainting was used.

Reproduce with Python + Pillow (12.3.0 used), official NCNN Windows binaries
and the realesrnet-x4plus.bin/.param model files:
python scripts/upscale-background.py --source reference/original-assets/pond.jpg --tool-dir PATH_TO_NCNN --output PATH_TO_RESULTS
The script writes pond-atlas-4x.png; this is the approved source for map extraction.
