# Water HD 参数配置说明

适用于 HD 1.x 随机风正式版，不适用于经典版 `wallpaper/`。配置入口为源码中的
`wallpaper-hd/settings.js`，或解压安装包根目录的 `settings.js`。
修改后重新加载壁纸生效，没有参数设置窗口，也不自动保存预览时的对照操作。
局部叶片弯曲已作为废案归档，不属于本配置。

普通 `index.html` 仅保留点击／拖动水面和壁纸引擎控制，不加载对照面板或预览快捷键。
`preview.html` 保留轻风／强风请求按钮、暂停及效果对照；操作不会写回配置文件。
一个安装包、一套场景，两种风都会自动随机发生。

## 修改方法与生效范围

1. 备份 `settings.js`，用文本编辑器修改数值；它是 JavaScript 对象，不是 JSON。
2. 保留逗号、引号和括号，一次只修改一组有关联的参数。
3. 完全重新加载壁纸。风调度在创建场景时初始化，部分着色器常量在加载时编译。
4. 若修改了离线标定参数，先按文末命令重建贴图，再重新加载。

源码默认值只在 `settings.js` 维护。打包原样复制配置，不选择风模式。
包内文档仅供查阅；实际配置来自同目录下的 `settings.js`。

本文“建议试调”是视觉调整的起点，不是程序自动限制，也不代表整段范围都经过性能验证。
所有数字应为有限数；标为正数的字段不能设为零。

## 坐标与单位

- 时间采用模拟秒。暂停时风的周期、波纹和叶子都停止计时。
- 世界坐标原点在画面中心，X 向右、Y 向上；角度使用弧度。
- 横屏的世界高度为 `10 / 3`，宽度随宽高比变化；竖屏世界宽度为 2。
- 例如 640×360 横屏中，1 世界单位约为 108 像素。大窗口中的像素变化会更大。
- 贴图坐标 UV 则 X 向右、Y 向下，通常落在 0–1。
- 1 弧度约 57.3°；`responseTime` 等响应时间越大，跟随越迟缓。

## 两种风如何共同发生

两种风各有一个随机等待计时器。启动时立即抽取首个等待时间；每种风实际结束后，
再抽取该种风下一次等待时间。等待是从结束到下次最早开始的时间，不是固定周期。

| 配置位置 | 轻风 `wind.gusts.gentle` | 强风 `wind.gusts.strong` |
| --- | --- | --- |
| `wait` | `[25,45]` 秒 | `[150,240]` 秒 |
| `duration` | 13 秒 | 10 秒 |
| `driftSpeed` | 0.045（继承） | 0.11 |
| `responseTime` | 0.65（继承） | 0.55 |
| `waveHeight` | 0.010（继承） | 0.030 |
| `airSpin` | 0.5（继承） | 0.85 |

当前有风时，另一种到点只等待，不叠加、不打断。结束后抽取 `wind.gap` 的 2–5 秒平静时间，
再让已经到点的风开始。若都尚未到点，则继续平静。等待先到者先发生；恰好同时到点时轻风优先。

每种风最多保留一次待发生事件，不会积压多阵。因另一阵风而推迟时，实际间隔可能超过 `wait` 上限。

每阵开始时从 `wind.direction` 均匀抽取方向，并整阵固定。默认覆盖 360°，水纹和浮叶漂移共用方向。
叶子保留跟随惯性，风结束后逐渐减速。

单阵使用正弦平方强度曲线，半程达到峰值，首尾强度与变化率为零。
所有计时都随模拟暂停；预览关闭 G 只隐藏风的影响，调度仍随模拟时间继续。

## 风参数详表

公共参数位于 `wind`；两种风在 `wind.gusts` 中提供各自的等待、持续时间和强度覆盖值。

| 字段 | 默认值 | 作用与修改约束 |
| --- | --- | --- |
| `wind.gap` | `[2,5]` | 任意两阵风之间的最小平静时间范围，秒；两个值均 >0，低值 ≤ 高值。 |
| `wind.direction` | `[0,Math.PI*2]` | 每阵随机方向范围，弧度；0 向右，π/2 向上。两个值相同可固定方向。 |
| `wind.gusts.*.wait` | 见上表 | 启动及该种风结束后的随机等待范围，秒；两个值均 >0，低值 ≤ 高值。 |
| `wind.gusts.*.duration` | 13 / 10 | 单阵持续时间，秒，必须 >0；不需要小于等待时间。 |
| `wind.gusts.*.label` | 轻风 / 强风 | 预览按钮及状态中的名称，不影响模拟。保留 `gentle`、`strong` 两个键。 |
| `driftSpeed` | 0.045 | 风对浮叶增加的目标速度，世界单位/秒，必须 >0。建议 0.02–0.12。 |
| `responseTime` | 0.65 | 追随风速的时间常数，秒，必须 >0。建议 0.4–1.6；越大越迟缓。 |
| `waveHeight` | 0.010 | 风波高度，世界单位；0 仅关闭风波，保留漂移与旋转。建议 0.005–0.03。 |
| `waveNumber` | 5.2 | 波数，弧度/世界单位；波长约 `2π / waveNumber`。保持正数，建议 3–7。 |
| `waveSpeed` | 0.65 | 风波沿风向传播速度，世界单位/秒；0 表示波形不传播。建议 0.3–0.9。 |
| `airSpin` | 0.5 | 空中额外旋转上限，弧度/秒；0 关闭此项，建议 0–0.9。 |
| `airSpinFadeHeight` | 0.18 | 接近水面时旋转开始减弱的高度，必须 >0，建议 0.1–0.3。 |

强度字段可以在 `wind.gusts.gentle` 或 `wind.gusts.strong` 中覆盖；改公共值会影响未覆盖该字段的风。
`gap` 与 `direction` 是整个调度器的设置，不应放进某一种风的覆盖对象。

空中旋转沿叶子原有自转方向增加；随机风向控制水纹与平移，不会把叶柄强行转向风向。
落水后停止额外旋转，保留原本的缓慢自转。风不会改变叶子局部形状。

### 手动预览也遵守排队

“吹一阵轻风”和“吹一阵强风”只把对应风的到期时间提前到现在。
若有另一阵风或仍处于平静间隔，则等待；重复请求当前风不会重启它，重复请求待发生的风不会累积。
手动与自动使用相同的持续时间和强度曲线：轻风 6.5 秒到峰值，强风 5 秒到峰值。
按钮会开启风效果、解除用户暂停，但不会越过引擎暂停。状态显示当前种类、强度、方向以及等待中的风。

### 调整例子与旧配置迁移

让强风更少出现：将 `wind.gusts.strong.wait` 改为 `[240,360]`，其结束后等待 4–6 分钟再到期。
限制为偏向右上方的风：将 `wind.direction` 改为 `[0,Math.PI/2]`。
减弱强风水纹而保留漂移：仅把 `wind.gusts.strong.waveHeight` 从 `.030` 改为 `.020`。

旧的 `breeze` 参数对象、`windProfiles`、`defaultWindProfile`、`delay`、`period`、
`directionSpread`、`manualRise` 和 `manualDuration` 已移除，不再选择轻风版或强风版。
旧 `rare` 对应现在的 `strong`，单阵强度数值保留。`features` 中的 `breeze` 键仍表示整体风效果。
不要把旧配置整体覆盖回来；按新结构迁移需要保留的数值。

## 渲染与叶子数量

| 字段 | 默认值 | 作用与约束 |
| --- | --- | --- |
| `render.maxFPS` | 60 | 绘制帧率上限，正数；通常用 30 或 60。引擎给出的更低上限仍会生效。模拟更新不直接绑定这个绘制上限。 |
| `render.maxDPR` | 2 | 设备像素比上限，正数；1 可降低高分屏开销，2 更清晰。 |
| `render.gridRows` | 96 | 水面网格行数，正整数；建议 64–96。调低会降低细水纹的精度。 |
| `render.maxColumns` | 600 | 超宽屏网格列数上限，正整数。最坏情况下须满足 `(gridRows+1)*(maxColumns+1) <= 65536`。 |
| `scene.leafCount` | 14 | 叶子数量，整数且至少为 1；建议 8–20。设成 0 会使自动涟漪无法选择叶子。 |
| `scene.leafSize` | 0.55 | 叶片基准半尺寸，世界单位，>0。实际图块边长约为 `2*leafSize*scale`。 |
| `scene.leafScale` | `[0.4,0.5]` | 叶子出生时的缩放范围；两个值均 >0，最小值 ≤ 最大值。建议先保持默认。 |

## 普通漂移与落水

这些参数位于 `drift`，属于没有风时也存在的运动。

| 字段 | 默认值 | 作用与约束 |
| --- | --- | --- |
| `velocityX` | `[-0.006,0.006]` | 每片叶子出生时的水平速度范围，世界单位/秒。 |
| `velocityY` | `[-0.044,-0.036]` | 垂直速度范围；负值向下。建议保持负值，当前回收逻辑主要面向下落。 |
| `spin` | `[-0.09,0.09]` | 初始自转范围，弧度/秒。新飘落叶子取两倍，落水时再乘 0.25。 |
| `fallSpeed` | 0.15 | 高度下降速度，世界单位/秒，必须 >0。默认初始高度 0.65，约 4.3 秒落水。 |
| `settleTime` | 0.24 | 叶子跟随波面坡度、上下浮动和接触负载的时间常数，必须 >0。建议 0.15–0.5 秒。 |
| `flow` | `[0.012,0.006]` | X/Y 背景缓流幅度，世界单位/秒。两个 0 可去掉缓流，保留基础漂移。 |

速度与自转范围采用 `[最小值,最大值]`。默认向下漂移、有限尺寸与当前回收边界是配套的；
不要只把漂移改成持续向上而不同时修改回收逻辑。

## 点击、拖动与圆形涟漪

`waves` 控制圆形涟漪；它与风的方向性细波是两套相加的波形。

| 字段 | 默认值 | 作用与约束 |
| --- | --- | --- |
| `waves.maxSources` | 12 | 最多同时保留的圆形波源，整数且 ≥1；超出时移除最早波源。 |
| `waves.lifetime` | 6 | 波源寿命，秒，>0。 |
| `waves.speed` | 0.85 | 环状波传播速度，世界单位/秒，建议保持正值。 |
| `waves.height` | 0.018 | 涟漪高度基准，世界单位；还会乘触发强度和时间衰减。 |
| `waves.frequency` | 19 | 环状波的空间角频率，弧度/世界单位；越大波纹越密。 |
| `waves.width` | 14 | 波包高斯衰减系数，单位为世界单位的负二次方；越大波包越窄。 |
| `waves.rise` | 9 | 起波速度系数，1/秒；越大越快出现。 |
| `waves.decay` | 0.68 | 时间衰减系数，1/秒；越大消退越快。 |
| `waves.ambientInterval` | `[2.4,4.5]` | 自动小涟漪的后续间隔范围，秒，最小值 >0。首个时刻目前在 `world.js` 固定为约 2 秒。 |
| `waves.ambientStrength` | 0.13 | 自动小涟漪强度倍率，0 可使其不可见。 |
| `waves.landingStrength` | 0.75 | 叶子落水时的涟漪倍率。 |
| `input.spacing` | 0.085 | 拖动产生下一波源所需的最小移动距离，世界单位，建议 >0。 |
| `input.cadence` | 0.075 | 拖动产生下一波源所需的最小时间，秒，建议 >0。距离和时间条件必须同时满足。 |
| `input.clickStrength` | 1 | 点击涟漪倍率。 |
| `input.dragStrength` | 0.55 | 拖动涟漪倍率。 |

高度与强度建议保持非负。波包还受源码中的固定距离裁切约束；大幅调整波长、宽度或速度时需要重新检查边缘。
启动时有一处固定的小涟漪，不属于 `ambientStrength`。

## 水面与主光照

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `water.refraction` | 0.10 | 波面坡度引起的背景纹理位移倍率；0 关闭这项位移。建议 0.05–0.15。 |
| `water.normalScale` | 0.85 | 水面法线的坡度倍率，影响光照；不直接改变纹理位移。 |
| `water.diffuse` | 0.13 | 波动带来的漫反射亮度变化幅度。 |
| `water.sheen` | 0.15 | 水面微光变化幅度。 |
| `water.sheenPower` | 42 | 微光集中程度，正数；越大越集中。 |
| `light.direction` | `[-0.38,0.54,0.751]` | 指向光源的方向，近似单位向量；Z 必须 >0。修改后须重建树荫贴图。 |
| `light.ambient` | `[0.61,0.65,0.69]` | 叶子环境光 RGB 系数。 |
| `light.keyColor` | `[1.04,1,0.91]` | 叶子主光 RGB 系数，允许略大于 1。 |
| `light.keyStrength` | 0.53 | 叶子主光强度。 |
| `light.canopyStrength` | 0.48 | 树荫对叶子主光的衰减，建议 0–1。不会再次压暗背景中的树影。 |

修改上述强度通常只需重载；改变 `light.direction` 还要同步离线树荫。
没有曝光、全局调色、动态太阳或真实流体参数。

## 叶片外观与贴水姿态

`leaf.ridge`、`leaf.curl` 控制既有静态光照法线；已否决的局部网格弯曲另有归档。

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `leaf.ridge` | 0.32 | 主叶脉两侧的法线起伏强度。 |
| `leaf.curl` | 0.22 | 沿叶脉的静态法线弧度，仅影响光照。 |
| `leaf.normalTilt` | 0.9 | 浮动倾角影响叶片法线的倍率。 |
| `leaf.shear` | 0.20 | 整张叶片随倾角产生的投影剪切系数。 |
| `leaf.squash` | 0.24 | 整张叶片随倾角产生的投影压缩系数；建议保持默认，避免尺度反转。 |
| `leaf.turn` | 0.22 | 波面倾角引起的额外整片转角系数。 |
| `leaf.bob` | 0.45 | 波高引起的整片上下位移倍率。 |
| `leaf.contactShadow` | 0.07 | 贴水时阴影不透明度基准，建议 0–1。 |
| `leaf.airShadow` | 0.17 | 空中阴影不透明度基准，建议 0–1。 |
| `leaf.origins` | 8 组 UV，见配置文件 | 每种叶子的根部标定。改变后须重建接触贴图。 |
| `leaf.axes` | 8 组二维向量，见配置文件 | 各叶子的主叶脉方向，应保持近似单位长度。改变后须重建接触贴图。 |
| `contact.depth` | 0.0052 | 贴水细纹的凹陷深度系数，建议先小幅调整。 |
| `contact.directionalLight` | 0.12 | 接触边缘额外明暗提示强度。 |
| `contact.waveGain` | 14 | 波高与叶子滞后高度之差，对接触负载的放大倍数。 |
| `contact.waveLimit` | 0.16 | 接触负载相对 1 的最大上下浮动，建议 0–0.3，必须 <1。 |
| `contact.restTilt` | 0.045 | 贴水姿态的固定基础倾角系数。 |
| `contact.liftRange` | `[0.7,1]` | 每片叶子出生时抽取的翘起程度范围，建议 0–1。 |
| `contact.poses` | `[[1,0],[-1,0],[0,1]]` | 湿叶柄／翘叶柄／翘侧边三种姿态。保留三组结构，修改内容后须重建接触贴图。 |

根部、轴向、姿态属于美术标定，不建议为了调强弱而改它们。
它们与原始图集的八个叶片格子、接触小片段及阴影模型相互对应。

## 离线树荫标定

以下键位于 `light.canopy`。它们由 `scripts/build-hd-maps.py` 使用，
不在壁纸运行时计算。修改后仅刷新页面不会改变已嵌入的树荫贴图。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `resolution` | 512 | 树荫贴图分辨率，正整数，建议保持 512。 |
| `dark` | `[18,58]` | 暗色筛选的亮度阈值，0–255，低阈值 < 高阈值。 |
| `chroma` | `[10,38]` | RGB 最大最小通道差阈值，用于排除深蓝天空；低阈值 < 高阈值。 |
| `blur` | 7 | 贴图上的高斯模糊半径，像素，≥0。 |
| `levels` | `[0.10,0.64]` | 最终遮蔽值重映射阈值，0–1 且低值 < 高值。 |
| `projectionHeight` | 0.055 | 树荫投影的 UV 标定高度，不是真实树高。 |
| `scale` | 1.02 | 树荫贴图投影缩放，必须 >0。 |

从完整仓库根目录执行（需要 Node.js、Python 和 Pillow）：

```powershell
python scripts/build-hd-maps.py
python scripts/build-hd-maps.py --check
```

脚本更新派生图与嵌入的 `assets.js`、`maps.js`。解压的运行包不含离线脚本和参考素材，
这类标定应在完整源码中完成后再打包。普通风速、周期、明暗强度修改不需要运行它。

## 功能默认值

`features` 是源码默认值和预览对照定义，不是内置参数配置界面。
保留各对象的 `key`；修改 `enabled` 可改变默认效果，所有现有项默认均为 `true`。

| key | enabled 的作用 | 预览按键 |
| --- | --- | --- |
| `lighting` | 水面、叶片和接触细纹的光照 | C |
| `canopy` | 树荫对叶子主光的遮蔽 | S |
| `motion` | 整片随波倾斜、浮动及接触负载变化；不关闭基础漂移、风致漂移或空中旋转 | B |
| `breeze` | 风产生的细波、漂移目标和额外空中旋转 | G |
| `contact` | 叶缘接触细纹；不关闭叶子阴影 | T |
| `leaves` | 隐藏或显示叶子、阴影和接触细纹；模拟与涟漪仍继续 | L |

`label`、`group`、`code` 仅用于预览按钮文字、分组和快捷键，不调整物理参数。
当前没有 F 键或局部弯曲参数。废案中的配置不应复制回主版本。

## 打包与检查

从完整仓库根目录执行：

```powershell
node tests/hd-world.cjs
node tests/hd-breeze.cjs
node tests/hd-wind-scheduler.cjs
pwsh -NoProfile -File scripts/package-hd.ps1
```

生成一个 `dist/Water-HD-<版本>.zip`，包含两种随机风。Release 只上传壁纸安装 ZIP。
打包原样保留配置。若修改了接触或离线标定，还应运行开发文档中的相应检查。
