## Water (Autumn Leaves) 1.0.1

A stable release of the desktop recreation of the classic Android **Water** live wallpaper.

Original AOSP artwork, fourteen drifting autumn leaves, falling-leaf shadows, and interactive water ripples — with no fluid solver or online dependencies.

### Install

- **Wallpaper Engine:** [Subscribe on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3815903983).
- **Sucrose:** download `Water-Original-Sucrose-1.0.1.zip`, import it into the library, then choose **Use**.
- **Lively:** download `Water-Original-Lively-1.0.1.zip` and import it into the library. End-to-end Lively compatibility has not yet been verified.
- **Browser / source:** download the source archive and open `wallpaper/index.html` in a WebGL-capable browser.

Click the water for ripples. Press **Space** to pause or resume. Desktop input forwarding depends on the wallpaper engine's settings and focus.

### Animation and validation

The classic animation uses a fixed 30 ms simulation step and renders at up to approximately 33 FPS. Wallpaper Engine's lower FPS setting is respected; the author's personal FPS setting is not included in the package.

Browser interaction, simulation checks, and rendered border checks at 16:9, portrait, and 32:9 passed. Strong and weak ripple cases show no white padding at the image edges. The updated Wallpaper Engine project is also available through the existing Workshop item.

`SHA256SUMS.txt` contains checksums for the two import packages. GitHub's automatic source archives contain the whole repository and are not engine import packages.
