## 下载与安装

下载 **Water-HD-1.0.1.zip**，一个包包含轻风与强风。

- Sucrose / Lively：导入 ZIP。Lively 实机导入仍待验证。
- Wallpaper Engine：解压后以 `index.html` 创建网页壁纸。
- 浏览器：打开 `index.html` 试用；打开唯一的 `preview.html` 对照效果。

正式壁纸没有配置面板。需要调整时编辑 `settings.js`，参考包内参数文档。

此版移除了重复的强风预览入口，精简使用说明，并统一打包版本信息。
Release 附件只提供安装 ZIP。原生引擎兼容性与持续 4K 性能尚未全面验证。

---

HD 1.0.1 cleans up the package and documentation. Water, leaves and random wind are unchanged.

Download **Water-HD-1.0.1.zip**. Import it into Sucrose / Lively, or extract it and create a Wallpaper Engine web wallpaper from `index.html`. Native Lively import remains unverified.

`index.html` is the normal wallpaper; `preview.html` is the single comparison preview. The redundant strong-wind preview has been removed. Edit `settings.js` and reload to customize; the Chinese parameter reference is included.

This release contains only the wallpaper ZIP. Native engine compatibility and sustained 4K performance have not been comprehensively verified.

[Installation guide](https://github.com/Kandecho/Water-live-wallpaper/blob/hd-v1.0.1/README.md)
