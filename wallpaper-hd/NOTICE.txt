This HD runtime embeds derived pond and leaf artwork, reconstructed offline
with RealESRNet. Leaf processing cleans tiny detached alpha dust and edge
colors, separately reconstructs each sprite's RGB, and resamples original
alpha. preview.jpg is a browser screenshot of the HD runtime.

Changes include WebGL 1 rendering, analytic waves with exact derivatives,
shared directional water/leaf lighting, positional canopy attenuation,
stable wet/dry floating poses, wave-driven motion, local meniscus refraction,
offline contact/shadow maps, premultiplied sampling and mipmaps, click/drag
ripples, desktop engine hooks and time-based motion up to 60 FPS.
This HD version is not an exact reproduction of the original RenderScript.
There is no fluid solver, soft-body simulation or runtime image processing.
The separately maintained classic version remains in wallpaper/.

Upscale project: https://github.com/xinntao/Real-ESRGAN
Inference: https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan
Model weights and inference binaries are not distributed with this release.
Reproduction scripts and asset hashes are included in the source repository.
