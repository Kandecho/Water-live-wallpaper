Water (Autumn Leaves) HD
Version: 1.0.1

INSTALL
Sucrose / Lively: import this ZIP into the wallpaper library.
Wallpaper Engine: extract and create a web wallpaper from index.html.
Browser: open index.html directly to try the scene.
Keep the extracted files together. No server or internet connection is needed.

USE
Click or hold and drag the water for ripples. Gentle and strong gusts occur
randomly in the same scene. Each has a random direction and waits for the other.
The normal wallpaper has no configuration panel.

PREVIEW AND CUSTOMIZATION
preview.html is the single comparison preview: pause, compare effects, or
request a gentle or strong gust. These controls do not save settings.
Edit settings.js and reload for lasting changes; see CONFIGURATION.zh-CN.md.

COMPATIBILITY
HD has passed browser, simulation and artwork checks. Native engine import
and sustained 4K performance are not fully verified; Lively testing is pending.
The renderer respects Wallpaper Engine pause and lower FPS settings.
